# Error-free-text
В этом репозитории содержится исходный код веб-приложения автоматической корректировки текста. Приложение принимает от пользователя запрос с текстом для исправления, в ответ отдаёт текст с исправленными опечатками.
## Стек технологий:
1. **Java 17**
2. **Spring Boot 3.5.16**
3. **СУБД: PostgreSQL 17**
4. **Система сборки: Gradle 9.8.0**
5. **Контейнеризация: Docker**
6. **Система управления миграциями БД: Liquibase**
7. **Lombok**
8. Тестирование:
   - **Unit-тесты: JUnit5, Mockito**
## Запуск
Для запуска приложения необходимо установить и запустить **Docker**.
1. Склонируйте репозиторий:
   ```
   git clone https://github.com/Amigos489/error-free-text.git
   ```
2. В терминале **IDE** или в консоли, находясь в директории проекта, выполните команду:
   ```
   docker build -t error-free-text
   ```
3. После сборки **docker-образа** запустите приложение командой:
   ```
   docker compose up -d
   ```
Для работы с приложением можно воспользоваться инструментом для тестирования **API** **Postman**:
**https://www.postman.com**

Приложение доступно по адресу: 
**http://localhost:8081/error-free-task/api**

Для проверки орфографии в тексте приложение использует **API** сервиса **Яндекс Спеллер**:

**https://yandex.ru/dev/speller**

Перед отправкой запроса приложение проверяет текст на содержание цифр и **URL**-адресов. Если слово содержит **URL**-адрес или цифры, то при проверке оно будет проигнорировано. Неверное употребление ПРОПИСНЫХ/строчных букв в словах за ошибку не считается. Подробнее о настройках в документации **Яндекс Спеллера**:

https://yandex.ru/dev/speller/doc/ru/reference/speller-options

## Документация API
1. **POST /tasks** - создать задачу на исправление текста

   **Требование к телу запроса:**
   - корректный параметр Языка (EN или RU),
   - текст должен содержать минимум 3 символа,
   - текст не может содержать только спецсимволы и цифры.
   
3. **GET /tasks/{id}** - найти задачу по идентификатору
   
   **В зависимости от статуса задачи исправления текста могу возвращаться следующие форматы ответов:**
   - **NEW** -> { status }
   - **COMPLECTED** -> { text, status }
   - **COMPLECTED_WITH_ERROR** -> { status, errorMessage }
