## О проекте
Данный репозиторий содержит исходный код веб-приложения автоматической корректировки текста. 
Пользователь отправляет приложению запрос на исправление текста, в ответ получает текст с исправленным опечатками.
## Стек технологий
1. **Java 17**
2. **Spring Boot**
   - **Spring Data JPA**
   - **Spring Web**
   - **Spring WebFlux**
4. Система сборки: **Gradle**
5. Контейнеризация: Docker (docker-compose)
6. Управление миграциями баз данных: **Liquibase**
7. Lombok

Для исправления опечаток приложение обращается к сервису **Яндекс Спеллер** https://yandex.ru/dev/speller
